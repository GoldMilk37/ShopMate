# 商品详情：SKU-40001

## 基本信息
- 商品ID：SKU-40001
- 商品名称：PureWave 10kg 变频滚筒洗衣机
- 品牌：PureWave
- 类目：家电 / 大家电 / 洗衣机
- 价格区间：2,199-2,899 元

## 核心卖点
1. 10kg 大容量，四口之家被单床罩一起洗
2. BLDC 变频电机，运行噪音 52dB（图书馆级），夜洗不扰眠
3. 60°C 除菌洗，婴童衣物可高温洗
4. 洗净比 1.08（国标一级为 1.03）
5. 空气洗功能：不能水洗的外套、抱枕可除味除尘

## 安装与适配要求
- 预留宽度 ≥ 595mm + 两侧各 20mm 散热间隙
- 进水压 0.03-1MPa，老小区高层水压不足会影响进水速度
- 需接地插座，功率 2,000W，普通 10A 插座可承载（需确认线路非老化铝线）

## 适用人群
- 三口/四口之家，洗衣量大
- 有婴幼儿家庭（高温除菌 + 空气洗）
- 夜间洗衣的上班族（低噪音 + 预约洗）

## 不适用场景
- 单身/两人小家庭（容量过剩，6kg 款更划算，见 FAQ）
- 阳台未做防水的老房子（滚筒脱水震动有共振风险，需确认地面水平）
