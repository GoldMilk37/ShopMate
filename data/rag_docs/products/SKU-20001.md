# 商品详情：SKU-20001

## 基本信息
- 商品ID：SKU-20001
- 商品名称：SoundCore 旗舰降噪耳机 Max
- 品牌：SoundCore
- 类目：数码 / 耳机 / 蓝牙耳机
- 价格区间：799-899 元

## 核心卖点
1. 主动降噪深度 45dB，中低频高频全面覆盖（高频降噪为全系最强）
2. 单次续航 10 小时，配合充电盒总续航 40 小时
3. 双动圈单元 + LDAC + LHDC 双高清编码
4. 支持无线充电 + 反向充电（充电盒可作应急充电宝给手机供电）
5. 多点连接：同时连接两台设备，通话自动切换

## 适用人群
- 音质党：双高清编码 + 双动圈，本系列音质天花板
- 商务人士：多点连接 + 反向充电，差旅友好
- 对降噪有极致要求：45dB 全频段覆盖

## 不适用场景
- 预算 600 元以内（可选同系列 SKU-10001 Pro，599 元）
- 仅用苹果手机且无安卓设备：LHDC/LDAC 均不支持 iOS，只能用到 AAC
