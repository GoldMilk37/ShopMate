# 蓝牙耳机选购指南

## 一、按需求选
- 通勤降噪：优先看降噪深度（>35dB）
- 运动健身：优先看防水等级（IPX5 以上）和佩戴稳固性
- 音质优先：优先看音频编码（LDAC/LHDC）和动圈单元
- 预算有限：300-500 元档位性价比最高

## 二、按预算选
| 预算 | 推荐档位 | 代表商品 |
|---|---|---|
| 300 以下 | 入门 | SKU-10003 |
| 300-600 | 主流 | SKU-10001 |
| 600-1000 | 旗舰 | SKU-20001 |

## 三、避坑提示
- 降噪深度标注虚高，建议看实测
- “Hi-Res 认证”不等于音质好
- 续航标注通常是单次+充电盒总和，注意区分
