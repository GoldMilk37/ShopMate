## 二、要不要烘干？先看两件事
1. 所在地区：南方回南天/梅雨、无晾晒条件 → 烘干价值高；北方干燥且阳台宽敞 → 烘干利用率低
2. 烘干容量 < 洗涤容量（如 10kg 洗 / 7kg 烘）：一次洗的量要分两批烘

## 三、五个必看参数
| 参数 | 怎么看 |
|---|---|
| 噪音 | 洗涤 ≤55dB 安静（可夜洗）；脱水 70dB 左右属正常 |
| 洗净比 | 国标一级 1.03，越高洗得越干净 |
| 电机 | 认准 BLDC 变频直驱：静音、耐用 |
| 安装条件 | 预留宽度、水压、地漏落差（≥800mm）、接地插座 |
| 保修 | 整机与电机分开看，电机长保修含金量高 |

## 五、常见误区
- 「空气洗」去异味不去油污，不是万能洗（详见家电品类 FAQ Q3）
- 羊毛/真丝即使有专用档位也可能缩水变形，贵价衣物建议送洗
- 烘干即烘即穿是理想值，厚外套常需二次晾晒；买前对「微湿感」有预期
- 大家电安装排期：大促后 1-3 天属正常，别把安装慢当成产品问题
