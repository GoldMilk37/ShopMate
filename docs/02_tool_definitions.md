# Function Calling 工具定义总览

| 工具名 | 类型 | 用途 | 安全级别 |
|---|---|---|---|
| query_order | 查询 | 查询订单状态与明细 | 只读 |
| query_stock | 查询 | 查询商品实时库存 | 只读 |
| query_price | 查询 | 查询商品实时价格 | 只读 |
| track_logistics | 查询 | 查询物流轨迹 | 只读 |
| apply_after_sale | 执行 | 提交退换货申请 | 写操作（需确认） |
| transfer_to_human | 执行 | 转人工客服 | 写操作 |

## 调用原则
1. 只读工具可由 LLM 自主调用，无需用户二次确认
2. 写操作工具必须走「提案 → 用户确认 → 执行」流程
3. 所有工具调用需记录日志（用户ID、工具名、参数、结果、耗时）
4. 工具超时时间统一设为 3s，超时降级为话术回复
